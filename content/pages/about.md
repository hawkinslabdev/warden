title: About
description: What this status page is and how it stays up to date.
---

A self-contained status page. It checks your configured sites on a timer and keeps the history in its own local SQLite database, nothing external to run or register with.

The status page itself was never written by hand. It renders live from that history on every request: which monitors are up, their 24-hour uptime, planned maintenance, recent incidents.

Everything else here (this page, the guide, the deploy instructions) is a plain Markdown file, the same as it would be on [Teatime](https://github.com/hawkinslabdev/teatime), the blog engine this project grew out of.
