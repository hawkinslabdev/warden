description: What this status page is and how it stays up to date.
---

This is Warden: a self-contained status page. It checks the sites you configure itself, on a timer, and keeps the history in its own local SQLite database, no external monitoring backend to run or depend on.

The status page itself is never authored by hand, it's rendered live from that history on every request, so what you see there is always current: which monitors are up or down, their 24-hour uptime, any planned maintenance, and recent incidents.

Everything around it, this page, the guide, the deploy instructions; is a plain Markdown file, the same way it would be on [Teatime](https://github.com/melosso/teatime), the blog engine Warden grew out of.
